## Recent Work

### Core-X Smart Poultry Automation Platform

Built a production platform spanning a Next.js monitoring dashboard, Go API server, React Native/Kotlin tablet app, and Kubernetes-based delivery workflow.

- Implemented multi-tenant RBAC with organization, farm, flock, and widget-level authorization
- Added Redis distributed locks to control scheduler concurrency in multi-replica Kubernetes environments
- Implemented OTA update integrity checks using SHA256 verification on both server and app sides
- Applied AI-assisted development with policy documents, critic review, and automated test gates
- Product LLM scope: client-side integration only, including chat UI/widget, API proxy, and JWT-based access control

### Healthcare Admin System and Website

Led front-end maintenance and improvement for a Next.js healthcare admin system and public website.

- Reworked repeated admin screens for clearer operational use
- Improved form, data-fetching, and state flows with React Hook Form, React Query, and Zustand
- Applied 4-language i18n and schema.org Microdata-based SEO improvements
- Improved Next.js standalone build and bundling workflow

### Zzalkak Online Media Editing Web Service

Built a media editing web service covering UI, auth, payment, file handling, deployment, and SEO.

- Implemented the service with Next.js, React, TypeScript, MongoDB, and cloud infrastructure
- Connected social login, payment flow, and media processing pipeline
- Moved browser-heavy encoding flow toward server-side processing to reduce bottlenecks

### AR Photo Kiosk

Developed a Windows kiosk and operation tools for an AR photo/video album service.

- Built Electron/Vue-based kiosk UI and device operation flows
- Integrated INICIS and UBCN card payment terminals
- Connected cameras, photo printers, card printers, logs, installer, and field operation tooling
